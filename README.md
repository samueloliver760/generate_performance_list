Cara penggunaan:
1. Tekan tombol "Code" (tombol warna hijau) lalu klik Download ZIP
2. Buka excel "BICF15 Generate PPT.xlsm, jangan lupa untuk enable content terlebih dahulu
3. Ke tab "Developer" kemudian ke Visual Basic
4. Copy paste code yang akan digunakan dan isi bagian "xxxx" dengan API dan direktori templete PPT
5. Tekan tombol Play (10 dari kiri) untuk menjalankan programnya, tunggu hingga prosesnya selesai

Catatan:
1. Untuk competition_round, digunakan untuk Grand Prix juga, ubah code pada roundtype_id untuk mengubah dari Competition Round ke Grand Prix
2. Untuk mengubah kompetisinya, pergi ke folder API yang dibutuhkan lalu ganti kodenya competition_id, Codenya seperti berikut:
  CP-0004 = BICF 15 (2026)
  CP-0005	= SWCF 2026 
  CP-0006	= YWCF 2027 
  CP-0007	= IBCF 2026 
  CP-0013	= BICF 16 (2027)
